# 星陵会館 シミュレーション

このプログラムは、星陵会館内での退場シミュレーションを実行するものです。

## 必要なもの
- Python 3.10以上
- インターネット接続（最初のライブラリインストール時のみ）

---

## 実行前の準備

### 1. Python をインストールする
Python が入っていない場合は、先にインストールしてください。

インストール時は、可能なら  
**Add Python to PATH**  
にチェックを入れてください。

---

## 実行方法

### 1. このフォルダをダウンロードして展開する
ZIPで受け取った場合は、右クリックして展開してください。

### 2. ターミナルを開く
このフォルダを開いた状態で、PowerShell または VSCode のターミナルを開いてください。

### 3. 必要なライブラリをインストールする
以下のコマンドを実行してください。

```bash
py -m pip install -r requirements.txt
