# 星陵会館 シミュレーション

このプログラムは、星陵会館内での退場シミュレーションを実行するものです。

## 必要なもの
- Python 3.10以上
- インターネット接続（最初のライブラリインストール時のみ）

---

## 実行前の準備

### 1. Python をインストールする
Python が入っていない場合は、先にインストールしてください。

インストール時は、可能なら  
**Add Python to PATH**  
にチェックを入れてください。

---

## 実行方法

### 1. このフォルダをダウンロードして展開する
ZIPで受け取った場合は、右クリックして展開してください。

### 2. ターミナルを開く
このフォルダを開いた状態で、PowerShell または VSCode のターミナルを開いてください。

### 3. 必要なライブラリをインストールする
以下のコマンドを実行してください。

```bash
py -m pip install -r requirements.txt
```

### 4. プログラムを実行する
以下のコマンドを実行してください。

```bash
py start.py
```

または、`start.py` をダブルクリックしてください。

---

## 実行後の流れ

`start.py` を実行すると、最初にモード選択画面が開きます。

- **研究用**
  - 条件ファイル（Excel）を読み込んで、描画なしで一括シミュレーションを行います。
- **観察用**
  - 画面上で条件を入力して、描画ありでシミュレーションを行います。

---

## 研究用の使い方

1. モード選択画面で **「研究用」** を押す  
2. 条件ファイル（`.xlsx`）を選ぶ  
3. **「シミュレーション開始」** を押す  
4. シミュレーション完了後、結果ファイルの保存先を選ぶ  
5. 結果ファイルを保存して終了する  

### 研究用でできること
- 複数条件をまとめて実行できます
- 平均step数や失敗回数を確認できます
- Excelファイルへ結果を書き出せます

---

## 観察用の使い方

1. モード選択画面で **「観察用」** を押す  
2. クラスごとの扉や開始ステップなどを入力する  
3. **「シミュレーション開始」** を押す  
4. 退場の様子が画面に表示される  
5. シミュレーション終了後、完了画面や結果画面を確認する  

### 観察用でできること
- 条件を手入力して試せます
- 退場の様子をアニメーションで確認できます
- 各条件の結果を画面で確認できます

---

## 条件ファイルについて（研究用）

研究用では Excel ファイル（`.xlsx`）を使います。

必要に応じて、画面内の  
**「サンプルファイルをダウンロード」**  
から見本ファイルを作成してください。
